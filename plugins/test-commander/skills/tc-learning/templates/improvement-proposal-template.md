## Scope

- **Project guidance** — applies to this project; lands in
  `learning/promoted-guidance.md` under `--apply`.
- **Core improvement** — if a lesson argues for a change to Test Commander's own
  shipped doctrine, that is a separate `core-promotion` proposal for a human to
  take upstream as a plugin PR. Test Commander never edits its own shipped
  methodology automatically (Open Question Q6).
